# 一件事的一句话和两步

## 一句话

**如果你做了一个东西（文件、表格、笔记、代码都算），别人拿到它，能在不问你的情况下用完——它才算做完了。**

## 第一步：在你的东西最上面写两行

```
做这个的人：__________（写名字）
我做它的时候是什么状况：__________（写三个词：时间、地点、当时在想什么）
```

写不出第二行，就在第二行写：「我写不出来。」

## 第二步：递给第二个人之前，问自己一句

**「他看完这两行，会不会知道该找谁？」**

如果不会，把第一行的名字换成一个他认识的人。

## 为什么只有这两步

因为大部分「没做成的事」，缺的不是内容，是这两行。没有这两行，别人拿到它只能猜；有这两行，最差的情况是他说：「我找不到你。」

## 一个更低的版本

如果你现在连两行都不想写，那就只做一件事：

**写一句话，让一个不认识你的人读完能复述给第三个人。**

复述不需要他认同，只需要他记住。而「能被复述」是这件事最低的门槛。

---

*这份东西本身按它自己的标准测过：你读完上面两行，不需要问我，就知道该怎么在你的文件上加那两行。*
