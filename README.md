# 一件事的一句话和两步

## 一句话

**如果你做了一个东西（文件、表格、笔记、代码都算），别人拿到它，能在不问你的情况下用完——它才算做完了。**

## 第一步：在你的东西最上面写两行

```
做这个的人：__________（写名字）
我做它的时候是什么状况：__________（写三个词：时间、地点、当时在想什么）
```

写不出第二行，就在第二行写：「我写不出来。」

## 第二步：递给第二个人之前，问自己一句

**「他看完这两行，会不会知道该找谁？」**

如果不会，把第一行的名字换成一个他认识的人。

## 为什么只有这两步

因为大部分「没做成的事」，缺的不是内容，是这两行。没有这两行，别人拿到它只能猜；有这两行，最差的情况是他说：「我找不到你。」

## 一个更低的版本

如果你现在连两行都不想写，那就只做一件事：

**写一句话，让一个不认识你的人读完能复述给第三个人。**

复述不需要他认同，只需要他记住。而「能被复述」是这件事最低的门槛。

---

*这份东西本身按它自己的标准测过：你读完上面两行，不需要问我，就知道该怎么在你的文件上加那两行。*

---

## 为什么是这个做法，而不是别的

**因为别的做法都要求别人先做点什么。**

- **写一份完整的方法论** → 要求读者先有时间读。
- **做一个工具或模板** → 要求读者先装、先学。
- **写一篇长文解释它的价值** → 要求读者先相信。
- **做一个检查清单** → 要求读者先承认自己需要检查。

**而这两行不要求任何事。** 你只要在你已经做完的东西上，加两行字。最差的情况是第二行写不出来——而「写不出来」本身就是结果。

**为什么不是更多行？** 因为第三行开始就要解释，而解释会让它变成一份文档，而不是一个动作。

**为什么那个人可以是任何人？** 因为这两行不传递知识，只传递位置——「这是谁做的、他在什么状况下做的」。位置不需要理解，只需要被看见。

---

## 它不适用于谁

- **不适用于「你还没有做出任何东西」的情况。** 如果你现在手上没有一件做完的东西，这两行没地方写。
- **不适用于「你已经在卖，而且卖得不错」的情况。** 那时候你缺的不是位置，是别的。
- **不适用于「你需要一个方法去做新东西」的情况。** 这不是方法，这是在做完之后加的两行。
- **不适用于纯粹给自己看的记录。** 如果那个东西永远不会离开你的硬盘，这两行没有意义。

**它不是给「想学营销的人」的，也不是给「想提升效率的人」的。它只给一种人：手上有做完了的东西，但从来没有在上面写过自己名字的人。**

---

## 它是不是打算卖

**不是。**

这份东西没有价格、没有付费入口、没有版权声明。它不指望被买，也不指望被引用。它唯一指望的是：有一个人在自己的文件上加了那两行，然后他发现第二行写不出来。

**而如果它哪天真的被人拿去卖了，那和它当初的意图无关——而那时候它需要一个新的说明。**
